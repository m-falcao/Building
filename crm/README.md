# Elo — CRM local

Execute `python server.py` nesta pasta e abra http://localhost:8765.

Sem instalação de pacotes. Requer Python 3. O servidor atende somente neste computador.

Persistência: `data/state.json`. Cofre Obsidian: `Obsidian`.

Cada cartão representa uma empresa e um módulo. Mova por arraste ou pelo seletor da página da empresa. Dados de demonstração são criados no primeiro acesso.

Limites e decisões: `Obsidian/Inicio.md`, `Obsidian/Decisoes.md` e `Obsidian/Pendencias.md`.
